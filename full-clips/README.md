按原问卷第 5、12、16、22 题的顺序答题。导出的 CSV 沿用原题号和场景编号。每次答题随机决定左右位置，测试设置在左右各出现两次。

三个视频都从原片开头播放，保留完整画面和原速。较短的参考视频播完后停在最后一帧。两侧候选播完后，三个视频一起重播。

答卷在线保存后，可下载服务器返回的 CSV 文件。在微信内也可以复制答卷链接，在手机浏览器打开后下载。链接包含这 4 题的匿名答案。没有收到在线保存回执时，仍可复制链接或完整 CSV 内容。
