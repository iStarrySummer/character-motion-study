[Questionnaire](https://istarrysummer.github.io/character-motion-study/) · [Researcher statistics](https://istarrysummer.github.io/character-motion-study/stats.html) · [v20](https://istarrysummer.github.io/character-motion-study/v20/) · [v19](https://istarrysummer.github.io/character-motion-study/v19/)

The questionnaire opens directly on the current question. Compare the head, eyebrow, and mouth movements in A and B with the red-framed reference, then choose one. Each of the 30 questions uses the existing five-round schedule. Answers save locally and sync to the results service. After question 30, select 完成 to open the export screen. In WeChat, copy the download link into a phone browser to save the CSV, or copy the answer text directly. The link carries the completed answers in its URL fragment and works without a server receipt or shared browser storage. New video clips require a network connection. The preview at `?preview=1` keeps its answers local.

The researcher key opens the results page. Totals include incomplete sessions and count the latest saved answer per participant and question. Reports use the actual settings behind randomized candidate positions. The Audio comparisons use TTS-N for Penny and Leonard and TTS-E for Sheldon. Leonard’s LoRA trials use Sheldon’s weights.
