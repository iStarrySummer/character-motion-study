The questionnaire opens directly on the current question. Compare A and B with the red-framed reference, then choose one. Each of the 30 questions uses the existing five-round schedule. Answers save locally and sync to the results service. Download a CSV at any time after answering. New video clips require a network connection. The preview at `?preview=1` keeps its answers local.

The researcher key opens the results page. Totals include incomplete sessions and count the latest saved answer per participant and question. Reports use the actual settings behind randomized candidate positions. The Audio comparisons use TTS-N for Penny and Leonard and TTS-E for Sheldon. Leonard’s LoRA trials use Sheldon’s weights.
