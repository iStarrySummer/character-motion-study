# Character Motion Study · v28

[Questionnaire](https://istarrysummer.github.io/character-motion-study/) · [v28 statistics](https://istarrysummer.github.io/character-motion-study/stats.html) · [v27 questionnaire](v27/) · [v27 statistics](v27/stats.html) · [Four-question retest](full-clips/)

Each of the four rounds contains one Audio and one LoRA comparison for each of Penny, Sheldon and Leonard. Odd questions place the selection file’s first candidate on the left. Even questions place it on the right. The center button advances after a choice. The CSV records the displayed settings and the chosen setting.

The browser resumes the current sheet. After question 24, 再答一份 starts a new submission. 本机以前的答卷 lets people export earlier completed sheets from the same browser. In WeChat, copy the download link into a phone browser or copy the answers. Preview sessions at `?preview=1` stay on the device. Each submission has its own ID and counts independently in v28 statistics.

Audio uses TTS-N for Penny and Leonard and TTS-E for Sheldon. Leonard’s LoRA comparison uses Sheldon’s weights.
